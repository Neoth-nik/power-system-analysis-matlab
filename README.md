# Power System Analysis and Renewable Energy Integration

MATLAB implementations of Newton-Raphson power flow analysis, optimal load scheduling, and renewable energy grid integration.

## Overview
This repository contains simulation scripts and modular solvers developed for power system optimization and smart grid analysis.

## Key Features
- **Load Flow Analysis:** Newton-Raphson iterative power flow solver.
- **Optimal Load Dispatch:** Hydro-thermal scheduling and economic dispatch formulations.
- **Renewable Integration:** Solar and wind variability analysis models.
